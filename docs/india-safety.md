# India Safety Defaults

WhisperCare is configured for India-first escalation:

- National emergency: `112`
- Ambulance defaults: `108`, `102`
- Tele-MANAS: `14416`, `1-800-891-4416`
- KIRAN: `1800-599-0019`

These values are read from `config/app.yaml`. The assistant must not diagnose, prescribe, or replace a Registered Medical Practitioner.
